Relie ton téléphone une fois

Le téléphone copie tes comptes, tes clés et tes stats depuis AllMyStats sur ton PC. Ensuite il marche tout seul, sans le PC : il récupère ses stats sur Internet.

1Sur ton PC : AllMyStats > Paramètres > Téléphone, coche « Relier mon téléphone ».
2Mets le téléphone sur le même Wi-Fi que le PC (juste le temps de la liaison).
3Scanne le QR code affiché sur le PC.

Ou tape l'adresse et le code affichés sous le QR code :

Les connexions HoYoLAB, Riot, Roblox et Activision restent sur ton PC : le téléphone utilise tes clés d'API et les infos publiques de tes comptes.
