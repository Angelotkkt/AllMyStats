Installer en une minute

Pas d'installation compliquée : un seul fichier, et AllMyStats se met à jour tout seul ensuite.

  1. Télécharge AllMyStats.exe

    Lance-le. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires puis Exécuter quand même.

  2. Connecte tes comptes

    Sur la page de chaque jeu, « Se connecter » ouvre la vraie page de connexion du jeu. Ton mot de passe ne passe jamais par AllMyStats.

  3. Joue

    Active « Toujours actif » dans les Paramètres : tes stats, ton temps de jeu et les mises à jour arrivent tout seuls.

Sur ton téléphone

L'appli Android affiche AllMyStats de ton PC, par ton Wi-Fi : toutes tes stats, partout dans la maison.

Télécharger pour Android
Gratuit · Android 7 et plus

  1. Installe l'APK

    Ouvre AllMyStats.apk sur ton téléphone. Android demande d'autoriser l'installation depuis ton navigateur : accepte, c'est normal pour une appli hors Play Store.

  2. Active le téléphone sur le PC

    Dans AllMyStats sur ton PC : Paramètres, Téléphone. Si Windows le demande, autorise AllMyStats sur les réseaux privés.

  3. Scanne le QR code

    Dans l'appli du téléphone : Scanner le QR code. Elle s'ouvre ensuite directement sur tes stats.

Sur iPhone, pas d'appli (Apple ne permet pas d'en installer hors App Store) : ouvre dans Safari le lien affiché sous le QR code, sur ton PC, puis Partager, « Sur l'écran d'accueil ».

Fait pour ne plus y penser

Pas de cookies à chercher, pas de fichier à retélécharger.

Une petite vérification par minute, une actualisation complète toutes les 30 minutes, même fenêtre fermée.

Les nouveautés arrivent par Internet et s'installent quand l'appli est fermée. Si une version plante, AllMyStats revient à la précédente.

Tes comptes restent à toi

Questions

C'est gratuit ?

Oui, entièrement. Pas de compte AllMyStats, pas de pub.

Pourquoi Windows dit que l'appli n'est pas reconnue ?

AllMyStats n'a pas de signature numérique payante, donc Windows SmartScreen ne la connaît pas encore. Clique sur Informations complémentaires puis Exécuter quand même. Télécharge-la uniquement depuis cette page.

Où sont gardées mes stats ?

Sur ton PC uniquement, dans le dossier AllMyStats de %APPDATA%. Rien n'est envoyé ailleurs.

Pourquoi une clé HenrikDev pour Valorant ?

Riot ne donne pas d'accès direct aux stats Valorant pour ce genre d'appli. HenrikDev est l'API utilisée par les trackers : la clé est gratuite (api.henrikdev.xyz, Dashboard, API Keys) et se colle une seule fois dans les Réglages de Valorant.

Comment mettre à jour ?

Tu n'as rien à faire : AllMyStats vérifie toutes les 10 minutes. Pour l'avoir tout de suite : Paramètres, Mises à jour, Vérifier maintenant.
